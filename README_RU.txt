==============================================================================
STEGGO SCRIPT / CHIPS MAKER PRO (РУССКАЯ ДОКУМЕНТАЦИЯ)
Создано: Alexander Belmont, Gemini и Grok
==============================================================================

Это универсальная программа для создания Чипсов — шифрованных файлов для общения с нейросетями.

Приложение позволяет кодировать текст в графические изображения ("чипсы") 
и декодировать их обратно, используя 4 режима кодирования:

1. DCT Стегонаграфия (Стего) — Скрытое встраивание данных в спектр 8x8 
   блоков DCT по цветовым каналам RGB (невидимое для глаза шифрование).
2. Код Брайля (Брайль) — Графическая сетка 6-точечных символов Брайля 
   с функцией точного обратного распознавания.
3. Азбука Морзе (Морзе) — Непрерывный визуальный сигнал тире и точек 
   с динамическим масштабированием.
4. QR-коды (QR-код) — Прямое кодирование текста в высокоплотные 
   QR-чипсы с автоматической коррекцией ошибок и мгновенным декодированием.

СПОСОБЫ ЗАПУСКА
------------------------------------------------------------------------------

Способ 1: Готовый EXE / ZIP архив (Windows)
1. Скачайте SteggoScriptPro_v1.0.0.zip или .exe по ссылкам выше.
2. Распакуйте архив (если скачали ZIP) и запустите SteggoScriptPro.exe двойным кликом.

Способ 2: Запуск из исходного кода Python
Если вы хотите вносить изменения или изучить исходный код:

1. Клонируйте репозиторий:
   git clone https://github.com/Limmweb/steggo-script-pro.git
   cd steggo-script-pro

2. Установите необходимые зависимости:
   pip install pillow numpy scipy opencv-python qrcode

3. Запустите программу:
   python main.py
